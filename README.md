

Este é um projeto da minha página pessoal desenvolvido com HTML e CSS e adaptável a dois tamanhos de tela diferentes.

O layout foi desenvolvido com base em um modelo criado no Figma.

- Cabeçalho com nome e menu
- Seção de apresentação com imagem e texto
- Seções de hobbies e locais visitados
- Área para feedback com campo de nome e mensagem
- Rodapé com ícones e botão de contato

   Recursos

- Layout responsivo usando apenas HTML e CSS
- Estilização simples com foco em boa organização visual
